# TSLB1114 Academic Explorers

Student-facing resources for English Language Skills in Academic Context.

- `index.html` is the course hub at https://tslb1114.vercel.app/. It links to the existing Topic 1 Listening Lab and Topic 2 notes.
- `reading.html` contains the Topic 3 Reading Explorer and its paired-text activity.
- `writing.html` contains the Topic 4 Writing Explorer and Writing Studio.
- `lecture-notes.html` contains printable, MK-aligned notes for Topics 3 and 4.

The site is static and deploys to Vercel without a build command. Existing `/course` bookmarks redirect to the new course hub, while the original Reading Explorer homepage redirects to `/reading` on its original hostname. Keep Reading and Writing on the same hostname for the source-note handoff. Practice drafts are stored by hostname, so students can reopen drafts saved on the original hostname from its `/writing` page.
