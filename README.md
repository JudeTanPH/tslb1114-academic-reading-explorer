# TSLB1114 Academic Explorers

Student-facing resources for English Language Skills in Academic Context.

- `course.html` is the course hub. It links to the existing Topic 1 Listening Lab and Topic 2 notes.
- `index.html` is the original Topic 3 Reading Explorer entry point, now with a paired-text activity.
- `writing.html` contains the Topic 4 Writing Explorer and Writing Studio.
- `lecture-notes.html` contains printable, MK-aligned notes for Topics 3 and 4.

The site is static and deploys to Vercel without a build command. Serve the files from one origin for the Reading-to-Writing handoff. Practice drafts stay in browser storage.
